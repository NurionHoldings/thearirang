# 관리자 전자문서 작성

홈에서 관리자 로그인 후 **전자문서 작성하기**를 누르면 `/document-editor.html`에서 제목·수신·발신·작성일·본문을 작성합니다. 더아리랑 서식과 자동 A4 분할 미리보기를 제공합니다.

- **문서함에 저장 / 변경 저장**: 서버의 비공개 문서함에 저장하고 다시 열어 수정합니다. 총괄관리자 문서함과 각 층 문서함은 분리되며 다른 문서함의 ID를 알아도 열람·수정할 수 없습니다. 동일 층 관리자들은 해당 층 문서함을 공유합니다.
- **새 문서로 저장**: 현재 내용을 별도 문서로 보관합니다. 동시 수정 충돌이 발생했을 때 기존 내용을 덮어쓰지 않고 사본으로 남길 수 있습니다.
- **PDF 다운로드**: 미리보기 각 페이지를 브라우저에서 렌더링해 PDF로 내려받습니다. PDF 본문은 이미지로 출력됩니다. 텍스트를 선택할 수 있는 출력이 필요하면 **인쇄**에서 PDF 저장을 사용할 수 있습니다.
- **작성 파일 다운로드 / 불러오기**: `arirang-document` 버전 1 JSON을 보관·복원합니다. 원래 서버 문서 ID나 권한은 파일에 포함하지 않으며 불러온 문서는 새 문서로 저장합니다.

본문은 6만 자 이내입니다. 자동 서버 저장은 실행하지 않으며 저장 전 변경 상태를 표시합니다. 문서를 전환할 때 미저장 변경을 확인합니다. 세션 만료가 확인되면 화면의 문서와 입력값을 지웁니다. 브라우저 localStorage에는 비공개 본문을 저장하지 않습니다.

서버 API는 `/admin-documents`와 하위 경로에서 매번 관리자 인증, 서버에서 계산한 문서함, 입력 형식·크기, 쓰기 Origin, 수정 ETag를 검증합니다. 파일은 Netlify Blobs에 문서별 객체로 저장하며 Production과 Preview를 분리합니다. 공개 경로에는 작성기와 회사 서식만 배포하며 작성한 문서는 포함하지 않습니다.

검증: `npm run typecheck`, `node --test tests/netlify/admin-documents.test.mjs`, `npm run build`. Playwright가 있는 환경에서 `DOCUMENT_CHROMIUM_EXECUTABLE=/path/to/chromium node tests/document-editor-browser.cjs`로 저장·재조회·수정·JSON·PDF·모바일·세션 만료 동작을 확인합니다.
