# 아리랑마켓 홈·상세 디자인

업로드 참고 화면 9718.jpg(상품 목록), 9716.jpg(기획전·상세)의 검정·차콜 바탕, 버건디 탐색 띠, 골드 강조색을 적용했다. 참고 사진이나 타사 문구·판매수치·쿠폰 약속은 사이트에 복제하지 않았다. 다판다.shop은 검색 도구로 접근되지 않아 첨부한 두 화면을 시각 기준으로 사용했다.

- `public/market-palette.css`: 마켓에만 적용하는 화면용 테마. 모바일 상품 목록 1열, 데스크톱 3열·태블릿 2열. 큰 사진과 흰색 가격, 대비가 있는 보조문구.
- 홈: 기존 사진 자산을 활용한 대형 이미지 배너, 실제 작동하는 신선식품 바로가기, 전문관·3단계 카테고리·상품 목록.
- 상세: 큰 이미지, 상품명·판매단위·실제 등록 가격, 상품정보·배송·구매안내 이동, 고정된 닫기·하단 동작. 모바일 전체 화면 상세.
- AI 예시 카드에서도 상세 안내를 열 수 있다. 구매·가격·재고를 임의로 생성하지 않으며 판매 준비 중 버튼은 비활성 상태다.
- 결제·배달 연결 준비 안내, 상품 업로드 우선순위, 업체 편집 및 로그인 권한 유지.
- 테마는 `@media screen`으로 한정하여 공개자료 인쇄 스타일에 영향을 주지 않는다.

검증: 마켓 회귀 테스트, 상세 열기·닫기·원래 분류 유지·예시 구매 차단, 빌드 및 타입 검사.
