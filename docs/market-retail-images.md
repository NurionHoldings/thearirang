# 소분류 판매상품 이미지

46개 소분류마다 한 판매 단위가 보이는 AI 상품 사진을 사용한다. 접시·음료잔·조리 연출 대신 팩, 봉지, 병, 통 등 실제 유통 포장을 중심으로 제작했다. 인증·산지·브랜드·가격을 임의로 표시하지 않는다.

- 자산: `public/assets/market/leaves/{category}--{leaf}-retail-v2.webp` (640×640)
- 생성 방식: 내장 ImageGen, 개별 자산마다 별도 생성
- 전체 프롬프트: `docs/assets/market-retail-image-prompts-v2.json`
- 품목명·판매 단위: `public/market-retail.mjs`

## 노출 및 편집

실제 상품이 없는 검색·소분류 화면에 판매 준비 중 이미지 예시를 보여준다. 이 카드는 재고·가격·장바구니가 없는 이미지 안내다. 클릭하면 해당 소분류로 이동한다. 관련 없는 검색어에는 이미지를 표시하지 않는다.

실제 등록 상품은 업로드 사진을 우선한다. 사진이 없으면 소분류 대표 이미지와 AI 생성 안내를 표시한다. 운영자·해당 업체의 상품 편집 화면에서 대표 이미지 선택 또는 직접 사진 업로드·교체가 가능하다. 기존 업체 권한·공개 조건·변경 충돌 검사는 유지한다. 실제 상품의 구성·수량은 등록 정보가 기준이다.
