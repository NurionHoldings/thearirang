# 아리랑마켓 이미지 및 업체·상품 편집

## 적용 이미지

청과·채소·정육/계란·수산·쌀/잡곡/농산물·간편식·냉동식품·유제품·과자/간식·음료·베이커리·양념/소스·생활/공산품 총 13종. 내장 image_gen 도구로 각 이미지를 별도 생성하고 확인한 뒤 WebP 960×720으로 크기·포맷만 최적화했다. 타 쇼핑몰 사진을 복사하거나 가상의 판매업체/가격/재고를 만들지 않았다.

파일: `public/assets/market/categories/{category}-v1.webp`. 생성 프롬프트 전체는 `docs/assets/market-category-image-prompts-v1.json`에 보존한다. 기본 제공 이미지는 ‘카테고리 대표 이미지 · AI 생성’으로 구분하고 상품 사진이 없는 경우에도 같은 안내를 붙인다. 원본은 생성 이미지 저장 위치에 유지한다.

홈 전문관, 전체 카테고리 사진 메뉴, 상품 목록·상세의 사진 영역, 업체 소개 카드에 연결했다. 실제 상품은 승인·영업 중인 업체가 공개한 상품만 조회한다. 카테고리 선택/검색 중에는 사진 전문관·전체 소개를 숨겨 상품 탐색에 집중한다. 생활·공산품 대분류와 세제/청소, 휴지/위생, 주방/생활잡화 소분류를 추가했다.

## 수정 방법

- 입점업체: 마켓 → 판매자 접속 → ‘업체정보·대표사진 수정’. 업체명, 공개 연락처, 주소, 소개, 배송비, 최소 주문액, 사진을 수정·저장한다. 입점 승인/지역 운영 권한은 부여하지 않는다.
- 상품: 같은 화면의 ‘내 업체 상품 등록’에서 등록하고 아래 목록에서 상품명, 중·소분류, 구성/중량, 원산지, 보관방식, 설명, 가격, 재고, 공개 상태, 사진을 수정한다.
- 운영자: 운영 관리 → 업체정보·대표사진 수정, ‘업체 상품 등록·편집’의 편집할 업체 선택에서 모든 업체의 동일 항목을 편집한다.
- 사진은 제공된 13종 선택 또는 JPG/PNG/WebP 2MB 이하 직접 업로드로 교체한다. 업로드 전 공개 사용 권한 확인이 필요하다. ‘분류 대표 이미지 자동 사용’을 선택하면 기존 업로드 연결을 해제한다. 옛 파일을 즉시 삭제하지 않아 저장된 원본을 파괴하지 않는다.

## 저장·권한

`20261102100000_market_media_profiles.sql`은 신규 사진 컬럼/업체 소개/공개 연락처/버전과 `market_media` 메타데이터 테이블만 추가한다. 기존 migration은 변경하지 않는다. 동시 편집은 버전으로 충돌을 감지하며, 주문 재고 변경도 상품 버전을 증가시킨다. 기존 주문 스냅샷·서명 계약서는 수정하지 않는다.

사진 실물은 Netlify Blobs에 고유 키로 저장하고, 업체 소속 메타데이터는 Postgres에 기록한다. Netlify Blobs 스킬을 적용해 production은 사이트 저장소, 다른 배포는 배포별 저장소로 분리한다. 비공개·미연결 사진은 소속 업체/운영자만 볼 수 있고, 공개 읽기는 승인·영업 중 업체의 대표사진 또는 공개 상품에 실제로 연결된 사진만 허용한다. 개인 주소·회계 자료용 저장소와 공유하지 않는다.

`/market-media` 업로드는 기존 마켓 세션·Origin·최대 크기·JPG/PNG/WebP 파일 시그니처와 소속을 검사한다. SVG/외부 URL/임의 경로는 허용하지 않는다. 다른 업체 업로드를 연결할 수 없다. 이미지 교체 저장 실패 시 고아 업로드가 남을 수 있지만 공개 연결은 되지 않는다. 보존기간·삭제 정책은 별도 관리 대상이다.

## 배경음악 교체

최신 업로드 `0718(2).MP3`(약 70분 8초)를 전체 유지했다. 원본은 변경하지 않고 AAC 64kbps / 44.1kHz의 약 5분 길이 15개 M4A로 변환하여 `public/assets/music-0718-v2/part-00.m4a` ~ `part-14.m4a`에 저장했다. 재생 종료 이벤트로 다음 구간을 재생하며 마지막은 처음으로 돌아간다. 구간 전환에 네트워크 상황에 따른 짧은 로딩이 있을 수 있다. 새 접속마다 자동재생을 시도하고 브라우저가 차단하면 첫 조작 때 재시도한다. 음악 정지 및 음량 조절은 유지한다.
