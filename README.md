# 더 아리랑 스토어 — 공간과 공정

구 대전 홍도동 아리랑백화점의 리모델링 관리 템플릿. Python 3.10 이상, 추가 패키지 불필요.

## 실행

```bash
export ARIRANG_ADMIN_PASSWORD='12자이상의관리자비밀번호'
python3 server.py
```

http://localhost:8000 접속. 관리자 로그인 후 업체, 공정, 점검, 현장사진, 공사비를 저장합니다. 비밀번호 미설정 시 읽기 전용입니다. 웹 공개 배포 시 HTTPS 리버스 프록시를 사용하고 `ARIRANG_HTTPS=1`, `HOST=0.0.0.0`을 설정하세요. 이 서버는 단일 프로세스 운영용입니다. 데이터는 `data/project.sqlite3`, 사진은 `data/uploads`에 저장됩니다. `ARIRANG_DATA_DIR`로 영속 디스크 경로를 지정하고 두 경로를 함께 백업하세요. 관리자 비밀번호와 실제 공사 기록은 Git에 올리지 마세요.

## 구성

- B1 주차장 / 1F 반값마트 400평 / 2F 약국도매유통 200평·배민마트 200평 / 3F 한의원 400평 / 4·5F 어르신 쉼터.
- 사용자 제공 현황: 1층 진열장·전기 공사 진행 중, 배민마트 영업 중, 약국도매·3~5층 인테리어 예정. 일정·업체·금액은 미등록.
- 4·5층 휴식/활동 분리는 제안이며 면적 미확정. B1 내부 예상도는 사진 미제공으로 표시하지 않음.
- 층 클릭, 현재/정비예상 전환, 6단계 공정표, 일정·담당·상태·근거, 자체 점검, 현장 사진 등록, JSON 기록 내보내기.
- 각 층 전기·내부미장·인테리어·냉난방기 업체명/담당/연락처. 1층 마트설계업체 추가. 2층 두 업무 영역 별도 관리.
- 공사비: 공종·품명/규격·수량·단위·단가·부가세·비고. 항목별 원 단위 반올림 후 공급가·부가세·총액 자동 합산. 계약/지급 금액과 구분.
- 서버 검증: 날짜 역전, 완료 담당·근거 누락, 최종 인계 전 선행 공정/점검 미완료, 비정상 산출액 차단. 자체 검증은 전문 검수나 인허가 판단이 아님.
- SQLite 저장, 변경 감사 기록, 버전 충돌 방지, 관리자 세션·CSRF 검증, 로그인 시도 제한, 사진 타입·용량 검증.

## 미리보기와 배포

`public` 폴더는 정적 호스팅으로 디자인을 볼 수 있지만 서버 저장·로그인은 작동하지 않습니다. 실사용은 위 Python 서버와 영속 디스크가 필요합니다. Netlify 정적 배포만으로 공사 기록을 서버에 저장할 수 있다고 표시하지 않습니다. 실배포·공개는 이 변경에 포함되지 않습니다.

## 이미지

첨부된 사진 10장을 외관 현장 참고자료로 사용했습니다. 촬영일은 미확인입니다. `public/assets/exterior.jpg`와 `interiors.jpg`는 내장 이미지 생성 도구로 제작한 콘셉트 예상도이며 실제 설계도·시공 승인도가 아닙니다.

프롬프트 요약: 기존 청록색 유리 5층 건물의 형태·교차로·전주·전선을 보존하며 외벽 청소, 보도 정비, 식재, 더 아리랑 스토어 간판 적용. 실내는 3×2 패널 순서로 반값마트, 약국도매유통, 배달마트 물류, 한의원, 어르신 휴식, 어르신 활동 공간을 텍스트 없이 건축 콘셉트 렌더링.

## 공사 전·후 이미지

층 선택 → 현장 기록 → 관리자 로그인 → 사진 구분 ‘공사 전 사진’ 선택 → 촬영 위치·일자·사진·기록 저장. 층 상단에서 ‘공사 전 / 공사 후 예상 / 나란히’ 전환이 가능합니다. 최신 공사 전 사진을 표시하고 모든 기록은 현장 기록에 남깁니다. 기존 분류 없는 사진은 현장 기록으로 유지합니다. 실제 준공 사진은 ‘공사 후 실사진’으로 별도 기록합니다. AI 예상도와 준공 실사진을 혼동하지 않도록 표시합니다.

후속 시안 반영 예상도 `public/assets/after-board-v2.jpg`: 기존 건물 형태와 1층 ‘더 아리랑 마켓’ 흰색 채널 간판, 다색 심벌, 청과 초록/정육 빨강/수산 파랑, 식재료 사진 입구 필름, 파란 주차장 입구 간판을 적용한 4개 뷰. 시안의 여러 대안 중 대표 요소를 조합한 AI 콘셉트이며 확정 디자인 아님. 지하 내부 실측과 2~5층 후속 시안은 미제공.

### 입력 흐름과 묶음 업로드

① 공사 전 사진: 장당 8MB, 한 번에 최대 20장. 촬영 위치·일자로 기록하며 비교 화면에서 사진 선택 가능. 일부 저장 후 실패 시 저장 장수를 안내합니다. ② 공사 적용·견적: 공사 내용·재료·색상·철거/유지 범위, 공종별 업체 상호·담당·연락처, 산출내역, PDF/사진 견적서 첨부(최대 8MB). ③ 예상도: 저장된 공사 계획과 AI 예상도를 나란히 확인합니다. 입력 내용으로 이미지가 자동 재생성되는 AI API 연결은 포함되어 있지 않습니다. 변경안별 예상도 생성은 별도 작업이 필요합니다. 주차장 간판은 파란 배경과 흰색 상호를 유지하며, 주차장 글자만 붉은색으로 수정했습니다.

## 아르카온의 목적과 역할

이 템플릿은 건물 현황 → 공사 범위 → 업체·견적 → 예상도 → 공정 → 검수의 연결을 관리합니다. 아르카온은 각 층의 자료 정리와 계획 검토를 돕습니다. 공사 전 사진, 공사 형태, 업체 상호/연락처, 산출내역, 견적서 누락과 공정 선후 관계를 규칙 기반으로 점검합니다. 영업 중 배민마트 보호, 약국도매 보관 계획, 쉼터 접근/피난, 붉은색 주차장 표식 같은 공간별 요구조건을 제시합니다. 입력 자료를 담은 예상도 제작 요구사항 TXT를 내보낼 수 있습니다. 사진 인식/OCR, AI 자동 재생성, 견적서 금액 자동 대조, 법적 적합성 판정은 미연결이며 이를 UI에서 명시합니다. 설계·계약·비용 지급·준공 승인은 관리자/전문가 역할입니다.

## 고령 소유주 음성안내

상단 ‘음성안내 켜기’를 한 번 클릭하면 Web Speech API로 한국어 안내를 재생합니다. 층·탭·비교 선택 시 현재 내용, 입력란 포커스 시 항목명, 저장·오류 결과를 읽습니다. 현재 화면 다시 듣기·정지·속도 조절 제공. 비밀번호와 입력값은 자동 읽지 않습니다. 기기/브라우저의 한국어 음성 엔진이 필요하며 지원되지 않는 경우 안내합니다. 사용자 첫 클릭 전 자동재생은 하지 않습니다. 한국어 음성의 품질과 실제 재생은 운영 기기에서 확인이 필요합니다.

## 로고 애니메이션

간판 시안의 청색·녹색·적색 각진 회전 심벌을 참고해 투명 PNG로 추출·재현했습니다(`public/assets/arirang-symbol.png`, 내장 이미지 생성 도구). 생성 재현이므로 원본 벡터와 미세한 차이가 있을 수 있습니다. 원본 AI/SVG 제공 시 교체 가능합니다. 심벌만 24초 주기로 천천히 회전하고 9초 주기로 은은한 빛이 지나갑니다. 상호는 고정됩니다. ‘로고 움직임 끄기/켜기’를 제공하며 기기 동작 줄이기 설정을 존중합니다.

## PC·모바일 반응형

PC는 건물/층 상세 2열, 1000px 이하 태블릿·모바일은 단일 열. 모바일에서도 상단 메뉴·음성안내·업체 입력·견적 첨부·사진 묶음 업로드를 유지합니다. 주요 입력 글자는 16px, 버튼 높이는 최소 44px, 소형 화면에서는 업체·공사비 폼을 세로로 재배치합니다. 전체 공정표만 명시적 가로 스크롤 영역을 사용합니다. 모바일 가로 모드도 별도 높이/사진 배열 적용. 브라우저 실화면과 실제 한국어 음성 재생 검증은 실행 환경 접근 제한으로 미완료입니다.
